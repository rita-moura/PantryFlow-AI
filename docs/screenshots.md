# Screenshots

The functional Angular shell exposes these portfolio routes:

- `/dashboard`
- `/pantry`
- `/recipes`
- `/meal-plan`
- `/shopping-list`
- `/settings/goals`

The public API demo is available at `GET /demo` and `POST /demo/plan`. Capture deployment-specific
screenshots after connecting the frontend to the hosted API; the repository keeps the UI and API
configuration environment-specific so local screenshots do not contain production credentials.
